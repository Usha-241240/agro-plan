# AgroPlan 🌱

Планировщик ухода за огородом — веб-приложение для учёта культур, планирования задач и ведения календаря работ.

## Возможности

- **Учёт культур** — название, дата посадки, место, заметки
- **Задачи по уходу** — полив, подкормка, прополка, обработка, сбор урожая
- **Фильтрация и поиск** — по статусу задач и названию культур
- **Календарь работ** — все задачи сгруппированы по датам
- **История** — выполненные работы в отдельном разделе
- **Локальное хранение** — данные сохраняются в `localStorage` браузера

## Быстрый старт

Откройте `index.html` в браузере — на лендинге нажмите **«Начать планирование»** или перейдите сразу в `app.html`.

### Локальный сервер (рекомендуется)

```bash
# Python 3
python -m http.server 8080

# или Node.js (npx)
npx serve .
```

Затем откройте [http://localhost:8080](http://localhost:8080).

## Использование

1. Добавьте культуру (название, дата посадки, место)
2. Создайте задачи по уходу, привязав их к культуре
3. Отмечайте выполненные задачи — статистика и история обновятся автоматически
4. Смотрите календарь, чтобы планировать работы на неделю
